# 📒 Saahukar Ledger – Digital Khata & Loan Ledger

**Saahukar Ledger** is an online digital khata and loan ledger management application designed to help manage customer records, loans, interest, payments, and receipts in one place.

🌐 **Live App:** https://saahukar-ledger.streamlit.app/

## 🇮🇳 About Saahukar Ledger

Saahukar Ledger is a simple digital ledger application for managing customer and loan records.

It helps users maintain organized records of:

* Customer details
* Mobile numbers and addresses
* Loan and principal amounts
* Monthly interest rates
* Loan dates
* Outstanding balances
* Customer payments
* Interest payments
* Principal payments
* Payment receipts
* Database backups

The application is designed to make traditional khata and ledger record management easier with a digital workflow.

## ✨ Features

### 📊 Dashboard

View an overview of your active ledger, including:

* Total active customers
* Outstanding principal
* Total accrued interest
* Total collected payments
* Overdue accounts

### 👤 Customer Management

Add and maintain customer information such as:

* Customer name
* Mobile number
* Address
* Government ID
* Loan amount
* Interest rate
* Loan date
* Collateral details
* Gold weight
* Notes

### 🔎 Customer Directory

Search active customers by:

* Name
* Mobile number

You can also filter customers with loans that are overdue for 30 days or more.

### 💳 Part Payment Management

Record customer payments and automatically calculate:

* Interest paid
* Principal paid
* Remaining principal

The application updates the customer's outstanding principal after a payment.

### 🧾 PDF Payment Receipts

Generate downloadable PDF payment receipts containing:

* Customer information
* Loan information
* Payment amount
* Interest paid
* Principal paid
* Remaining principal
* Receipt number
* Payment date and time

### 📁 Database Backup

Create a backup copy of the SQLite database for record keeping.

## 🎯 Who Can Use Saahukar Ledger?

Saahukar Ledger can be useful for people who need a simple digital system for maintaining customer and loan records, including small businesses and individuals who currently maintain loan or khata records manually.

This project is built using:

* Python

* ReportLab

## 🚀 Run Locally

Clone the repository:

```bash
git clone https://github.com/indoressag-ship-it/sahukar-ledger.git
```

Open the project directory:

```bash
cd sahukar-ledger
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
streamlit run Saahukar.py
```

Users should be careful when entering sensitive customer information such as government identification numbers, mobile numbers, addresses, and financial records.

Do not enter sensitive information unless you understand where the application stores and processes that information.
